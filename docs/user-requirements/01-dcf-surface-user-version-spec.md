## 1. 产品定位与目标用户

### 1.1 定位

DCF Surface 是面向终端用户的 **AI 记忆助手**，帮助用户回顾对话、获取洞察、管理任务。它不是开发者内部工具，而是一个看得见的"左膀右臂"。

**关键转变**：
- ❌ 从："G2 Dashboard — 全域对话回看"（工程视角）
- ✅ 到："我的 AI 记忆助手 — 回顾对话、获得洞察"（用户视角）

### 1.2 目标用户画像

典型用户场景：
- **日常使用**：在 ChatGPT、Claude、IDE Agent 等不同 AI 之间切换工作
- **遇到问题**：几周前聊过的内容想找回来，但忘了具体内容
- **想深入探索**：某个话题聊了好几次，想知道自己的认识如何演变
- **有行动项**：某次对话中产生了想法或任务，需要后续跟进

**用户需求特征**：
- 不懂什么"G2/G3/G4"、"DORC 状态机"、"四态链"
- 只需要能回答："我之前跟 AI 聊过什么？""我现在该做什么？"
- 期待一个清晰、直观、无摩擦的界面，而不是技术仪表盘

## 2. 核心用户需求（基于愿景 + 通用 UX 原则）

### 2.1 信息层级与认知负荷

根据 Miller's Law（7±2 法则）和渐进式披露原则：
- **首屏只展示最关键的 3-5 项信息**：今天发生了什么、还有什么未完成任务、有什么新推荐
- **更深的内容按需展开**：完整历史、原始对话、来路证据
- **避免技术术语**：所有标签、按钮、状态都用自然语言描述

**对比**：
```text
❌ 当前 G2 首页：
- "边界状态条"（NOT_OBSERVE/OBSERVE_CURRENT_ONLY/OBSERVE_AND_ARCHIVE）
- "缺口统计面板"（gaps: 0, gaps_size: 0）
- "事件计数器"（events_ingested: ...）
- "搜索框" placeholder: "q=..."

✅ 用户版应改为：
- "正在记录" / "暂停记录" / "仅用于当前"（配合图标和颜色）
- "历史记录完整度：100%"（而非缺口统计）
- "共记录 XX 轮对话"（而非事件计数）
- "输入关键词搜索对话..."
```

### 2.2 可见性与系统状态

根据 Nielsen Norman Group 启发式评估 和 **Glassmorphism 设计语言**：
- **授权状态必须一眼可辨**：用直观的视觉提示显示哪些 AI 正在被记录，哪个被排除
- **进度反馈**：同步时显示"正在保存..."、"已保存"；失败时用友好提示（非 HTTP 错误码）
- **离线状态**：Companion 断连时，不显示红色横幅和技术参数，而是**"Companion 未运行 - 点击启动"**

**视觉设计要点**：
- **绿色 = 安全/进行中**：正在正常记录
- **橙色 = 注意**：仅用于当前（不存档）
- **红色 = 停止/问题**：不读取、Companion 离线
- **灰色 = 未知/不可用**：暂时无法判断状态
- **磨砂玻璃效果**：侧边栏背景使用 `backdrop-filter: blur(20px)` + 半透明白底
- **渐变色板**：悬浮球采用蓝→紫渐变，动态呼吸灯效果（有新推荐时闪烁）
- **动效反馈**：展开/收起用时 300ms，EaseInOut 曲线；点赞/收藏时有微动画

### 2.3 用户控制与自由度

根据 Nielsen Norman Group 和 **Voice-first + Gesture-friendly 设计**：
- **窗口行为**：支持拖拽、缩放、最小化到悬浮球；默认居中或记住上次位置
- **隐私边界**：用户可以一键切换"完全暂停"、"仅本次会话"、"持续记录"
- **退出路径**：明显位置的"关闭/收起"按钮，符合 macOS 应用惯例
- **语音快捷命令**：按住 Cmd+Space 说出"暂停记录"、"查看今天对话"、"标记为任务"
- **手势支持**：双击悬浮球展开、三指捏合收缩、右滑显示快捷菜单
- **上下文感知**：自动识别当前 AI 类型（ChatGPT/Claude/IDE），切换到对应工具集

### 2.4 错误预防与恢复

根据愿景中的"带条件可信"原则和 **Data-driven Personalization**：
- **同步失败**：不说"FetchError"，而说**"保存失败，请检查网络连接"**并提供重试按钮
- **缺口诚实**：如果部分对话未完整保存，说**"XX 时刻的记录未保存完整"**，而非抽象的数字
- **撤回能力**：用户主动排除的对话，提供"撤销排除"入口（保留证据链）
- **个性化容错**：学习用户常见误操作模式，智能建议"您是否想恢复刚才排除的对话？"
- **渐进式提示**：新用户首次遇到复杂操作时，浮现引导气泡（类似 Duolingo 的微交互）

## 3. 2024 现代 UX 设计趋势融合

### 3.1 Bento Grid 模块化布局

**灵感来源**：Apple Promotional Materials、Linear、Notion

**特点**：
- 每个功能模块作为独立卡片，网格排列
- 卡片支持拖拽调整位置和大小（用户自定义仪表盘）
- 响应式重排：不同屏幕尺寸下自动重组

**示例结构**：
```css
.bento-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
.card {
  background: rgba(255, 255, 255, 0.7);
  backdrop-filter: blur(20px);
  border-radius: 12px;
  padding: 16px;
  transition: transform 0.2s ease, box-shadow 0.2s ease;
}
.card:hover {
  transform: translateY(-2px);
  box-shadow: 0 8px 16px rgba(0,0,0,0.1);
}
```

### 3.2 Glassmorphism 玻璃态设计

**灵感来源**：macOS Big Sur、Windows 11、Apple visionOS

**特点**：
- 磨砂玻璃背景效果
- 微妙的光影层次
- 透明度渐变营造深度感

**实现要点**：
```css
glass-panel {
  background: linear-gradient(135deg, rgba(255,255,255,0.9), rgba(255,255,255,0.7));
  backdrop-filter: blur(20px) saturate(180%);
  border: 1px solid rgba(255, 255, 255, 0.3);
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.1);
}
```

### 3.3 Microinteractions 微交互体系

**灵感来源**：Duolingo、Rive 动画、Framer Motion

**应用场景**：
- **点赞反馈**：心形跳动动画 + 粒子效果
- **卡片展开**：平滑高度过渡 + 淡入内容
- **推荐接受**：绿色对勾打钩动画 + "已添加到任务"提示
- **空状态插画**：加载时无数据时，展示柔和插图 + 引导语

### 3.4 Progressive Disclosure 渐进式披露

**灵感来源**：Linear、Vercel Dashboard、Notion

**策略**：
- **默认视图**：只显示最重要信息（今日摘要、最近对话）
- **进阶开关**："显示高级选项"按钮展开搜索过滤器、时间范围选择
- **详情折叠**：对话元数据、来路证据默认折叠，点击展开
- **上下文相关**：只在需要时才出现下一步操作（如点击推荐后才显示"接受/搁置/忽略"）

### 3.5 Dark Mode & Adaptive Typography

**灵感来源**：GitHub Dark Mode、Stripe Atlas、Spotify

**设计要求**：
- **自动跟随系统**：macOS 暗色模式自动切换
- **字体自适应**：字号随对比度调整（暗色模式下加粗 10%）
- **变量字体支持**：根据阅读距离调整字重（如 iPad 触控场景用更大字号）
- **高对比度模式**：满足 WCAG 2.1 AA 标准，支持强制高对比度主题

### 3.6 Voice-first + Gesture-friendly

**灵感来源**：Humane Pin、Apple Siri、Google Assistant

**交互方式**：
- **语音命令**：Cmd+Space 唤起，支持"查看今天的对话"、"暂停记录"、"标记为任务"
- **手势快捷**：双击悬浮球、三指捏合、长按呼出上下文菜单
- **触觉反馈**：支持 Haptic Touch（iPhone/iPad）提供轻触震动

### 3.7 Data-driven Personalization

**灵感来源**：Spotify Wrapped、Netflix、Amazon

**个性化维度**：
- **学习习惯分析**：识别用户最常使用的 AI（ChatGPT/Claude/本地）并置顶
- **时间规律预测**：工作日 vs 周末显示不同的摘要模板
- **兴趣领域聚类**：自动归类对话主题（如"项目规划"、"UI 讨论"、"新技术学习"）
- **优先级智能排序**：根据价值成熟度和时间敏感性排序推荐

### 3.8 Accessibility First

**灵感来源**：Microsoft Fluent Design、Apple VoiceOver、WebAIM

**无障碍特性**：
- **键盘导航**：Tab 顺序合理，支持 Cmd+K 快速搜索、Cmd+Arrow 快捷键
- **屏幕阅读器**：ARIA 标签完整，所有图标都有 alt text
- **焦点可见性**：Focus Ring 明显但不突兀（Blue 2px 边框）
- **多语言支持**：中英文无缝切换，预留日语/韩语接口
- **减小运动模式**：尊重系统"减少动态效果"设置，简化动画

## 4. 功能需求（按优先级排序，融合现代 UX）

### P0：MVP 必需功能（G1 活闭环验证前）

#### 3.1 首页：今日概览

**目标**：让用户知道"我昨天/本周/本月都做了什么对话"

**布局**：
```
┌─────────────────────────────┐
│ [标题] 我的 AI 记忆助手       │
│                              │
│ ┌── 状态卡片 ────────────┐   │
│ │ 🟢 正在记录           │   │
│ │  已持续 5 天            │   │
│ └───────────────────────┘   │
│                              │
│ ┌── 今日摘要 ────────────┐   │
│ │ 共 3 轮对话             │   │
│ │ 最后活动：10 分钟前     │   │
│ └───────────────────────┘   │
│                              │
│ ┌── 最近对话 ────────────┐   │
│ │ 🔍 搜索对话...          │   │
│ │ ● 项目规划 (2 小时前)   │   │
│ │ ● UI 讨论 (昨天)        │   │
│ │ ● 新功能建议 (3 天前)   │   │
│ └───────────────────────┘   │
└─────────────────────────────┘
```

**交互细节**：
- **标题区域**：大字体显示"我的 AI 记忆助手"，副标题小字"帮你回顾对话、获得洞察"
- **状态卡片**：
  - 左侧颜色圆点（绿/橙/红）+文字
  - 下方一行说明"已连续记录 X 天"或"上次记录于 X 小时前"
- **今日摘要**：三行统计（总对话数、最早时间、最新时间），数字加粗
- **最近对话列表**：
  - 每条显示主题、相对时间、简短预览（第一句话的前 50 字）
  - 点击进入详情
  - 右侧滑动出现操作菜单（编辑标题、删除、设为收藏）

**数据映射**（Companion API）：
| 用户需求 | Companion 端点 | 数据字段 |
|----------|---------------|---------|
| 授权状态 | `GET /rpc/boundary` | state, description |
| 今日摘要 | `GET /rpc/events/query?since=X` | count, earliest, latest |
| 最近对话 | `GET /rpc/material/projection` | id, title, preview, ts |

#### 3.2 对话详情页

**目标**：让用户"回到当时的现场"

**布局**：
```
┌─────────────────────────────┐
│ ← 返回列表      项目规划    │
│                              │
│ ┌── 元数据 ──────────────┐   │
│ │ 🕒 2 小时前              │   │
│ │ 🤖 通过 ChatGPT         │   │
│ │ 📁 项目话题卷宗          │   │
│ └───────────────────────┘   │
│                              │
│ ┌── 对话流 ──────────────┐   │
│ │ [你的提问] 怎么优化...  │   │
│ │                    ↓   │   │
│ │ [AI 回答] 建议从三个...  │   │
│ │                    ↓   │   │
│ │ [你的追问] 第二点再...  │   │
│ └───────────────────────┘   │
│                              │
│ ┌── 来路证据 ────────────┐   │
│ │ ○ 来自 ChatGPT 页面      │   │
│ │ ○ 原始 DOM快照(查看)     │   │
│ │ ○ 附件 3 个 (查看)        │   │
│ └───────────────────────┘   │
└─────────────────────────────┘
```

**交互细节**：
- **顶部导航**：返回按钮 + 标题（可编辑）+ 更多菜单
- **元数据区**：时间、AI 类型、所属话题卷宗（可跳转）
- **对话流**：
  - 每轮左右分列（用户 vs AI），头像区分
  - 支持滚动、长按复制、点赞/踩
  - 底部固定"继续对话"提示（链接到网页 AI）
- **来路证据**：折叠面板，默认收起；展开后显示来源 URL、截图缩略图、附件列表

**数据映射**：
| 用户需求 | Companion 端点 | 数据字段 |
|----------|---------------|---------|
| 对话列表 | `GET /rpc/material/projection?event_id=X` | sequence of events |
| 元数据 | `GET /rpc/boundary`, `POST /rpc/sync/github/pull` | source, adapter, boundary |
| 附件 | `GET /rpc/export?format=compact` | attachments array |

#### 3.3 隐私设置页

**目标**：让用户清楚"我的数据在哪里、怎么用、谁能访问"

**布局**：
```
┌─────────────────────────────┐
│ ← 返回列表      隐私设置     │
│                              │
│ ┌── 全局开关 ─────────────┐  │
│ │ ● 暂停记录所有对话      │  │
│ │   点击暂停后不会保存任  │  │
│ │   何新对话，但已有记录  │  │
│ │   仍可查看               │  │
│ └───────────────────────┘  │
│                              │
│ ┌── 对话级别设置 ─────────┐  │
│ │ ChatGPT                 │  │
│ │   ● 持续记录 (🟢)       │  │
│ │   ○ 仅用于当前 (🟡)     │  │
│ │   ○ 不读取 (🔴)         │  │
│ └───────────────────────┘  │
│                              │
│ ┌── 导出数据 ─────────────┐  │
│ │ 下载Markdown汇总        │  │
│ │ 导出完整JSONL            │  │
│ │ 同步到GitHub私人仓库     │  │
│ └───────────────────────┘  │
│                              │
│ ┌── 关于 ─────────────────┐  │
│ │ DCF Surface v1.0.0     │  │
│ │ GitHub: user/dcf       │  │
│ └───────────────────────┘  │
└─────────────────────────────┘
```

**交互细节**：
- **全局开关**：大号 Toggle 按钮，状态变化时有明确文字说明影响
- **对话级别设置**：列表显示每个适配器（ChatGPT、Claude、本地 AI）的状态，点击切换
- **导出数据**：三个操作卡片，每项说明格式和用途
- **关于区域**：版本号和仓库链接

**数据映射**：
| 用户需求 | Companion 端点 | 数据字段 |
|----------|---------------|---------|
| 全局状态 | `GET /rpc/boundary` | all states |
| 单个适配器 | `POST /rpc/boundary/update` | {adapter_id, state} |
| 导出 | `POST /rpc/export` | format: markdown/jsonl |
| GitHub sync | `POST /rpc/sync/github/push` | push status |

#### 3.4 悬浮球与侧边栏收缩

**目标**：符合愿景中"对话旁的卡片侧边栏"，随时够得着

**行为规范**：
- **默认状态**：72px 半透明圆球，悬浮在其他窗口顶层（alwaysOnTop: true）
- **点击展开**：平滑动画展开为 340×1200 侧边栏（保持置顶）
- **收起按钮**：侧边栏右上角"⚪"按钮，点击缩回球体
- **拖拽移动**：球体和侧边栏都可拖拽（macOS 习惯）
- **关闭窗口**：侧边栏模式下点击"×"直接隐藏（非卸载）

**视觉设计**：
- **悬浮球**：渐变色圆圈（蓝→紫），中心可能有动态提示点（有新推荐时闪烁）
- **侧边栏**：磨砂玻璃效果（backdrop-filter: blur），内容区半透明白底
- **动效**：展开/收起用时 300ms，EaseInOut 曲线

### P1：V1.0 完整体验（G2 显性界面）

#### 3.5 搜索与过滤

**功能**：
- **全文搜索**：搜索对话正文、标题、附件文件名
- **智能过滤**：按 AI 类型（ChatGPT/Claude/本地）、时间范围、话题卷宗筛选
- **搜索结果**：高亮关键词，展示片段上下文，支持点击跳转

**UX 要点**：
- 搜索框放在首页顶部，焦点即触发下拉（最近搜索历史）
- 结果分页加载，无限滚动
- 支持"在此结果中继续搜索"嵌套过滤

#### 3.6 AI 归纳卡片

**功能**：
- **自动总结**：每组对话结束时有 AI 生成的 3 句要点总结
- **观点卡**：识别出"锋利观点"，单独标记为卡片
- **设定卡**：提取用户偏好（如"我喜欢简洁的回答"）

**展示方式**：
- 对话详情页底部自动折叠"AI 总结"（默认收起）
- 首页新增"精彩观点"区域（每天最多 3 条）
- 卡片可点击"发射"：一键复制到剪贴板，或发送回当前 AI 对话

#### 3.7 推荐与任务中心

**功能**：
- **推荐列表**：系统推荐的未处理事项（基于材料成熟度评分）
- **优先度标记**：高（红色）、中（黄色）、低（灰色）
- **接受/搁置/忽略**：每个推荐有三种操作
- **任务转化**：接受后变成任务，进入 G4 生命周期

**推荐来源**：
- 跨对话关联（"你在 3 个月前也提到过类似问题"）
- 时间敏感（"你计划下周开始的项目"）
- 价值判断（"这个想法可能值得实施"）

### P2：G3-G7 进阶功能（按需引入）

## 4. 非功能性需求

### 4.1 性能要求

- **首屏加载**：< 1 秒（冷启动）
- **搜索响应**：< 300ms（索引命中）
- **对话加载**：< 500ms（100 轮内）
- **内存占用**：< 200MB（idle）

### 4.2 可靠性要求

- **数据完整性**：承诺归档的对话必须 100% 保存
- **缺口诚实**：任何丢失明确告知，不得冒充完整
- **离线可用**：已缓存数据可离线浏览；新建依赖 Companion

### 4.3 隐私与安全

- **本地存储**：默认只存本机（SQLite in ~/.dcf/）
- **加密可选**：支持 BitLocker/FileVault 外额外加密
- **明确边界**：每个适配器独立开关，拒绝批量默认同意
- **零残留**：设为"不读取"的窗口，DCF 完全不观察

### 4.4 国际化与无障碍

- **多语言**：中文优先，预留英语接口（i18n 结构化）
- **字体适配**：支持中英文混排（PingFang SC、Segoe UI）
- **高对比度**：满足 WCAG 2.1 AA 标准
- **键盘导航**：Tab 顺序合理，支持快捷键（Cmd+K 快速搜索）

### 4.5 平台适配

- **macOS**：遵循 Human Interface Guidelines
  - Cmd+C/V/X快捷键
  - 右键菜单
  - 暗色模式自动适配
- **未来扩展**：Windows/Linux 版本共享同一套 UI 逻辑

## 5. 与现有实现的差距分析

| 需求项 | 当前 G2 实现 | 用户版需求 | 差距等级 |
|--------|-------------|-----------|---------|
| 首页布局 | 工程术语（缺口条、边界状态条） | 用户语言（正在记录、对话摘要） | **高** |
| 数据展示 | 事件计数、哈希值 | 时间线、自然语言摘要 | **高** |
| 导航结构 | 单页 Dashboard（g2-dashboard.html 全宽） | 悬浮球→侧边栏分层 | **中** |
| 隐私设置 | 边界状态下拉框（NOT_OBSERVE 等枚举） | 可视化开关 + 文字说明 | **高** |
| 对话详情 | 无现成页面 | 需从零构建 | **高** |
| 搜索功能 | 基础 input[q] | 全文索引 + 过滤 | **中** |
| AI 卡片 | 无 | 自动总结 + 观点卡 | **高** |
| 推荐系统 | 无 | 优先级排序 + 接受机制 | **高** |

**结论**：G2 作为 MVP 技术验证可行，但作为用户版需要**重写 UI 层**，保留后端 API（Companion）。

## 6. 推荐实施方案

### 方案 A：全新用户界面层（推荐）

**思路**：
1. 创建 `seed/surface/user-home.html`（首页）、`user-detail.html`（详情）、`user-settings.html`（设置）
2. Electron 主进程改加载 `/user-home.html`，悬浮球/侧边栏共用同一组页面
3. Companion API 保持不变（向后兼容）
4. g2/g3/g4/g6 作为"开发者模式"保留在隐藏菜单入口

**优点**：
- 彻底分离用户关注点和工程复杂度
- 用户界面迭代不受旧代码干扰
- 开发者仍可调试 g2 原型

**缺点**：
- 初期工作量较大（约 3-4 周）
- 需要维护两套 HTML 文件树

**时间估算**：
- 第 1 周：user-home.html + 基础导航 + Companion 集成
- 第 2 周：user-detail.html + 对话流渲染 + 来路证据折叠面板
- 第 3 周：user-settings.html + 隐私设置交互 + 导出功能
- 第 4 周：测试打磨 + 悬浮球收缩动效完善

### 方案 B：渐进式重构 G2

**思路**：
1. 在现有 g2-dashboard.html 中拆分组件（Header、BoundaryBar、ConversationList）
2. 逐步替换标签为自然语言，调整信息层级
3. 添加子路由（#/home, #/detail/:id）单页化改造

**优点**：
- 代码复用率高
- 增量改动风险可控

**缺点**：
- 受限于原有架构（单页全屏设计）
- 难以实现悬浮球/侧边栏双层形态
- 工程术语遗留可能导致"修修补补"

**时间估算**：
- 第 1-2 周：拆分为组件 + 导航框架
- 第 3-4 周：首页文案和布局调整
- 第 5-6 周：详情页从零构建
- 第 7-8 周：设置页 + 综合测试

**强烈不推荐**：渐进式重构容易陷入"永远不够好"循环，建议直接采用方案 A。

## 7. 验收标准

### 7.1 可用性测试标准（5 人样本）

招募 5 名非技术背景用户，执行以下任务：

**任务 1：回顾对话**
- 引导语："你想找上周跟 AI 聊的一个话题，但忘了具体内容"
- 成功标准：3 分钟内通过搜索或列表找到目标对话，并打开查看详情
- 失败指标：询问"这里能不能搜"、找不到入口

**任务 2：暂停记录**
- 引导语："现在要讨论一个私密话题，不想被保存"
- 成功标准：找到隐私设置，切换到"不读取"状态，得到明确反馈
- 失败指标：找不到隐私入口、误操作其他设置

**任务 3：导出分享**
- 引导语："想把最近一周的对话总结发给同事"
- 成功标准：在设置页找到 Markdown 导出，生成文件并成功打开
- 失败指标：困惑"JSONL 是什么"、不知道如何选择格式

### 7.2 技术指标

- [ ] Lighthouse Performance > 90
- [ ] First Contentful Paint < 1s（冷启动）
- [ ] Time to Interactive < 2s
- [ ] Memory leak-free（连续使用 1 小时无增长）
- [ ] Off-line browsing: 已缓存对话可正常翻阅（Companion 断开）

### 7.3 回归验证

- [ ] Companion 原有 API 全部响应正常（test:legacy 11 个测试 green）
- [ ] Chrome 插件功能不受影响（test:chrome 11 个测试 green）
- [ ] Electron 打包后双击可启动，无控制台报错
- [ ] 悬浮球→侧边栏转换流畅，无闪屏/跳变

## 8. 待确认问题（需与你讨论）
