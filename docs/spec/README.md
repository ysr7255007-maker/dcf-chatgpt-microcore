# DCF 当前规范入口

更新：2026-08-07  
状态：**当前规范权威索引**

本目录存在多轮连续推演留下的规范。实现、设计、验收与人工阅读时，**先读本文件，再按下列顺序读取**。旧文件保留历史价值，但不得与更新裁决争夺当前实施权威。

## 当前权威顺序

1. `2026-08-07-DCF-Capability与公共设施当前规范.md`
   - 当前最高层架构增量裁决；
   - 冻结 Capability（能力）、Public Facility（公共设施）、Provider（提供者）、Shared Semantic Component（共享语义组件）、ExternalOperation（外部操作）与 World Composition（World 组合）；
   - 冻结 E0–E5 已验证的公共设施结构；
   - 对与 2026-08-04～08-06 规范冲突的部分拥有优先权。
2. `2026-08-07-DCF-证据采集与多源证据编译增量规范.md`
   - 当前前两个能力候选的最新 Discovery（能力发现）裁决；
   - 收敛“证据源采集管理”与“多源证据编译”的职责边界；
   - 明确采集侧负责输入复杂度、编译侧负责输出复杂度；
   - 明确来源输出优先采用 ECS（实体组件系统）小组件自由组合，多源证据编译通过公共语义组件查询式订阅，而不是依赖具体来源私有接口；
   - 不冻结最终组件字段、最终文件格式或第三方轮子选型。
3. `2026-08-06-DCF-功能包络与施工控制规范.md`
   - 当前施工控制规范；
   - 已同步为 Capability Registry（能力登记表）+ Capability Envelope（能力包络）+ Standalone World（独立 World）/ Composite World（组合 World）双验收；
   - Capability DAG（能力有向图）只作为派生视图，不再是人工维护的第一事实。
4. `2026-08-04-DCF-当前实施规范.md`
   - DCF 长期价值、现实 / 认知 / 行动分层、历史不可静默覆写等仍有效；
   - 其中“六层流水结构”“查询诱导语义场=查询层”“旧施工阶段”等与 08-07 新规范冲突的表达降级为历史推演。
5. `2026-08-06-DCF-锚定认知世界与查询求解公共能力规范.md`
   - 认知对象、修订、锚点、求解器等业务语义仍是重要来源；
   - 查询层以 08-07 新规范为准：语义引力场只是 Query Strategy（查询策略）之一；SQLite 是权威层，派生检索可替换、可删除、可重建。
6. `2026-08-06-DCF-个人叙事功能块实施规范.md` 及 2026-08-05 各专项规范
   - 继续作为功能需求和历史设计来源；
   - 其中把“个人叙事”或其他产品写成大一体内部流水的边界，不再自动拥有 Capability 划分权。
7. `../current-state.md`
   - 只记录当前已经确定什么、代码/实验真实处在哪里、下一步做什么。
8. `../adr/`
   - 保存为什么发生这些变化、实验依据和被替代路线。

## 冲突处理

若旧规范与 2026-08-07 新规范冲突：

> **保留旧文本作为历史，不做静默覆写；实施时以更新裁决为准。**

若新想法尚无行为证据：

> **先作为假设 / 候选，不得反向修改已验证公共边界。**

若未来实验推翻当前裁决：

> **新增显式 ADR（架构决策记录）/ 新规范记录转变，不删除本轮历史。**
